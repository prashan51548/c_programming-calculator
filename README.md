
# 🧮 Smart Calculator in C

A menu-driven calculator developed using the C programming language. This project performs basic arithmetic operations using user-defined functions and control structures.

## 📌 Project Description

The Smart Calculator is a simple command-line application that allows users to perform mathematical calculations. Users can select an operation from the menu, enter two numbers, and get the calculated result.

The program continues running until the user selects the Exit option.

## ✨ Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Division by zero error handling
- Menu-driven interface
- Continuous calculations using do-while loop
- Separate user-defined functions for each operation
- Invalid choice handling

## 🚀 How to Run the Project

### Step 1: Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/Smart-Calculator-C.git
```

### Step 2: Open the Project Folder

```bash
cd Smart-Calculator-C
```

### Step 3: Compile the C Program

```bash
gcc calculator.c -o calculator
```

### Step 4: Run the Program

For Windows:

```bash
calculator.exe
```

For Linux/macOS:

```bash
./calculator
```
